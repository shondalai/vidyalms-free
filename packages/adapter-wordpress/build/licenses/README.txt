react-remove-scroll-bar 2.3.8 declares MIT in its npm package.json but omits a
licence file from the tarball. The retained MIT licence is from the author's
repository, commit 7301c160fda44cb8cf2b9fdfde61efad35736196 (2025-05-21):
https://github.com/theKashey/react-remove-scroll-bar/blob/7301c160fda44cb8cf2b9fdfde61efad35736196/LICENSE

dependency's identity in THIRD-PARTY-NOTICES.txt at the plugin root. It does not
download licence text or change dependency versions during builds.
